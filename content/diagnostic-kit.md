<h2>Three routes, one decision at a time</h2>
<div class="product-grid">
  <div class="product-card">
    <p class="product-num">A</p>
    <h3>Mobile data cannot reach the server</h3>
    <p>When the phone says it cannot connect, or Plex Remote Access is red/unavailable. Check the client error, Remote Access state, WAN versus public IPv4, one TCP rule, firewall, Relay, and a private path if CGNAT blocks forwarding.</p>
  </div>
  <div class="product-card">
    <p class="product-num">B</p>
    <h3>It connects only indirectly</h3>
    <p>When playback works but Dashboard says Indirect or Relay. Confirm the connection mode, exposed port, double NAT, external reachability, CGNAT, and whether direct or private access is achievable.</p>
  </div>
  <div class="product-card">
    <p class="product-num">C</p>
    <h3>It connects but keeps buffering</h3>
    <p>When the library opens away from home but the stream stalls or transcodes badly. Compare bitrate with upload, test one lower quality, inspect CPU/transcode reasons, then run a 10-minute retest.</p>
  </div>
</div>

<div class="product-callout">
  <strong>Before Route A/B/C: entitlement precheck.</strong> A missing Plex Pass or Remote Watch Pass, an activation limit, or the wrong Plex account can look like a broken network path. The kit checks the entitlement first so you do not change router settings for a permissions problem.
</div>
