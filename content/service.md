<p>This is a one-to-one remote troubleshooting service for a Plex server you own. It is for the case where Plex works on your home network but fails when you leave home, switches to an indirect connection, or cannot play reliably on mobile data.</p>

<h2>What is included</h2>
<ul>
  <li>One existing Plex Media Server host and one playback client path.</li>
  <li>A 60-minute remote diagnostic session with a screen share and written chat.</li>
  <li>Checks for remote-access status, CGNAT, router forwarding, relay, Tailscale, reverse proxy, DNS, and client playback.</li>
  <li>A mobile-data playback test on the same video.</li>
  <li>A short written handover with what was checked, what changed, the test result, and rollback steps.</li>
</ul>

<h2>How the quote works</h2>
<ol>

<ul>

</ul>
